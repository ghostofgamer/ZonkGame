# Base: шаблон игр

Шаблон на Unity 6000.3 для мобильных и казуальных игр под Яндекс Игры, Игры ВКонтакте и RuStore.
Интеграция площадок, сохранения, реклама, покупки, язык и качество графики сделаны один раз.
Каждая новая игра начинается с копии этого репозитория (раздел «Новая игра из шаблона»).
Структура, стек и правила: [AGENTS.md](AGENTS.md).

## Где мы сейчас

Состояние на 24 сентября 2026 года.

Шаблон проверен на всех площадках (метка `template-v1`, тогда ещё под именем Farkle), затем код переименован
в нейтральный `Base.*`. После переименования нужна короткая проверка (раздел «Проверка шаблона»),
затем метка `template-v2`. Игрового кода в шаблоне нет, вместо игры тестовая сцена `Scenes/PlatformTest.unity`
с кнопкой на каждый метод площадки и общего слоя.

| Площадка | Состояние |
|---|---|
| Яндекс Игры | Готово: SDK, `LoadingAPI.ready`, язык из SDK (индикаторы `IT` и 文 зелёные), реклама, облачное сохранение, лидерборды. Покупки проверены в редакторе, товары в Консоли не заведены |
| Игры ВКонтакте | Готово: VK Bridge 3.0.2, реклама, сохранение в хранилище VK, выкладка из Unity. Лидерборды и покупки требуют своего сервера, недоступны |
| RuStore (Android) | Готово: Яндекс Реклама 8.4.0 (демо-блоки), локальное сохранение. Лидербордов и покупок нет |
| VK Play | Не планируется (24.09): площадке нужны платные игры с серьёзной графикой. Заготовка `Platform/VKPlay` осталась |

**Общий слой игры** (`Base.Services`, подключается `GameServicesInstaller`), одинаковый во всех играх:

- `ISaveStore`: сохранение по разделам с номером версии и миграциями. Если облако не прочиталось,
  запись в облако выключается до конца сессии, чтобы не затереть прогресс.
- `IEntitlements`: права игрока, например `no_ads`. Игра спрашивает право, а не покупку.
- `IPurchaseFlow`: покупка, выдача, восстановление при запуске, защита от двойной выдачи расходуемых товаров.
- `IRewardService`: награда «за рекламу или бесплатно» по правилам.
- `IInterstitialService`: interstitial по поводу («партия закончилась»), частота в одном месте.
- `AdPauseController`: пауза и выключение звука на время рекламы и при потере фокуса.
- `IQualityService`: уровень графики по типу устройства. `ILocalization`: язык из SDK, ru и en.

## Новая игра из шаблона

**Один раз, для самого шаблона:** на GitHub переименовать репозиторий (например, в `GameBase`)
и в Settings поставить галочку **Template repository**. GitHub Desktop подхватит новое имя сам.

**Для каждой новой игры:**

1. GitHub → репозиторий шаблона → **Use this template** → новый репозиторий с именем игры. Склонировать в GitHub Desktop.
2. Открыть в Unity 6000.3.23f1 (первый импорт долгий).
3. Поменять то, что своё у игры:

| Файл | Что поменять |
|---|---|
| `Assets/Scripts/Editor/ProjectIdentity.cs` | `ProductName` (название, можно по-русски), `BuildFileName` (имя APK латиницей), `AndroidPackage` (`ru.ghostofgamer.<игра>`, **после публикации в RuStore не меняется никогда**) |
| `vk-hosting-config.json` | `app_id` игры в VK (создать игру на dev.vk.com). Сейчас там ID «Зонк: Кости Фортуны» |
| `Assets/Scripts/Services/Monetization/MonetizationConfig.cs` | товары (ID как в консоли площадки), частота interstitial, правила наград |
| `Assets/Scripts/Platform/RuStore/RuStoreAdUnits.cs` | свои рекламные блоки из partner.yandex.ru перед публикацией (для тестов работают демо) |
| `Assets/Scripts/Core/Localization/LocalizationTable.cs` | тексты игры (ru и en) |
| Project Settings → Player | иконка, заставка, ориентация экрана |
| `README.md`, `AGENTS.md` | шапка README про игру; в AGENTS.md добавить раздел об игре, правила шаблона оставить |

4. Код игры: папка `Assets/Game/<Название>/`, в ней asmdef `<Название>` со ссылками на `Base.Core`, `Base.Services`,
   `Base.Platform.Abstractions`, `UniTask`, `Zenject`. Сборку добавить в `Assets/link.xml` с `preserve="all"`.
5. Zenject: сервисы игры, которые живут всё время, и миграции сохранений (`ISaveMigration`) биндятся в своём
   `MonoInstaller`, добавленном в список Mono Installers в `Assets/Resources/ProjectContext.prefab`.
   Сервисы одной сцены: `SceneContext` в сцене со своим инсталлером.
6. Build Settings: первой поставить сцену игры. `PlatformTest` оставить в проекте для проверки площадок, из сборки убрать.
7. В консолях площадок завести лидерборды и товары с теми же ID, что в коде.
8. Меню `Base/Platform/<площадка>`, затем `Base/Build/...`.

Исправления, сделанные в игре и касающиеся шаблона (`Assets/Scripts`), переносить в шаблон руками, и наоборот.
Когда игр станет три и больше, платформенный слой стоит вынести в UPM-пакет, чтобы исправления приходили обновлением.

**Фаркл** будет первой игрой из шаблона: пакет `ru.ghostofgamer.farkle`, VK ID 54765957.

## Проверка шаблона

После изменений в `Assets/Scripts` собрать площадки и пройти тестовую панель.

| Площадка | Как собрать и выложить | Где проверять |
|---|---|---|
| Яндекс Игры | `Base/Build/Yandex Games (WebGL)`, запаковать содержимое `Builds/Yandex` в zip, загрузить в черновик в Консоли | Консоль → «Открыть с debug-панелью» |
| Игры ВКонтакте | `Base/Build/VK Games + Deploy (dev)`: собирает и выкладывает сам, в конце кнопка «Открыть игру» | `vk.com/app<ID>` на ПК (без блокировщика рекламы) и в приложении VK на телефоне через «Избранное» |
| RuStore | `Base/Build/RuStore (Android APK)`, установить `Builds/RuStore/<BuildFileName>.apk` | телефон или эмулятор |

| Кнопка | Что должно быть |
|---|---|
| Статус | `initialized=True`, `sdkLang=ru`, `uiLang=ru`, правильный `device` (ПК → `PC`, телефон → `Mobile`), `saveLoaded=True cloudWriteBlocked=False` |
| Показать interstitial / rewarded | реклама показалась, во время неё нет звука, rewarded после досмотра `Rewarded` |
| Interstitial по правилам | первую минуту `skipped: first 60s after launch`, потом показ, повтор раньше 90 секунд пропускается |
| Награда (реклама или даром) | досмотреть: `Rewarded granted=True`; закрыть раньше: `Closed granted=False` |
| Сохранить (+1) → перезапустить игру → Сохранить (+1) | счётчик продолжился |
| Прочитать облако | `{"format":1,"sections":[...]}` с разделом `test_panel` |
| Купить no_ads | в редакторе `Success` и право `no_ads`; на Яндексе только когда товар заведён; на VK и RuStore `Unavailable` |
| Сбросить права | права пустые (на Яндексе купленное вернётся при следующем запуске) |
| Лидерборд | только Яндекс, лидерборд `score` должен быть заведён в Консоли |
| Сменить язык, Сменить качество | подписи и `level` меняются |

Если реклама на RuStore отвечает `NotAvailable`, смотреть в логе панели строки `[RuStore] … failed to load`.

## Отложено (не блокирует игры)

- **Сервер игры:** лидерборды на VK и RuStore, покупки на VK.
- **RuStore:** ключ подписи APK (создать перед первой публикацией и хранить с копией), карточка в консоли;
  облачное сохранение через GameCenter и платежи (Pay SDK) требуют ИП или юрлица. Pay SDK потребует переключить
  Application Entry Point с GameActivity на Activity и заново проверить Android-сборку.
- **VK:** размер окна на ПК (было 411×731: «Отображение» → широкоформатный режим и iframe 1000×700), ориентация на телефоне.
- **Качество:** настроить уровни в Project Settings > Quality (ужатие текстур и render scale на `Mobile`,
  при необходимости уровень `Medium` для планшетов), разрешение канваса в WebGL на телефонах с высоким devicePixelRatio.
- **Тексты игр:** пока в общей `LocalizationTable`. Когда текстов станет много, вынести в файл ресурсов игры.
- **UPM-пакет:** когда игр станет три и больше (см. выше).

Мелкие хвосты:

- Удалить остатки шаблона Unity: `Assets/TutorialInfo`, `Assets/Readme.asset`, `Assets/Scenes/SampleScene.unity`.
- Удалить дубликат решения `Far.sln`.
- Определиться с Managed Stripping Level (сейчас High). Менять только с проверкой в браузере.
- Папка `Test/` со скриншотами попала в коммит `YandexCompleted`. Если не нужна, убрать из git и добавить в `.gitignore`.

  `LoadingAPI.ready()`, и лоадер платформы оставался в состоянии ожидания. Исправлено:
  `PlatformInitializer` вызывает `NotifyGameReady()` сразу после инициализации;

  Причина: в комментарии `index.html` был записан абсолютный адрес хранилища `sdk.js`. Адрес удалён,
  в `AGENTS.md` добавлен запрет упоминать его в файлах игры.
- Сборка под Яндекс заработала в черновике: панель отрисована полностью, тексты на русском,
  индикаторы debug-панели `IT` и 文 зелёные, автоопределение языка принято.

  лидерборд `main` и товар `no_ads` пока не заведены.

  `Resources/Fonts/Roboto-Regular.ttf` (Apache 2.0), панель грузит его через `Resources.Load`.
- Индикатор 文 на debug-панели оставался красным («I18N is not used»), при этом индикатор лоадера показывал `IT`.
  Причина: обращение к `environment.i18n.lang` жило внутри моста и происходило только после старта Unity.
  Чтение языка перенесено в `initSDK()` на странице, сразу после `YaGames.init()`; мост берёт значение из `window.ysdkLang`.
- Тестовая панель в WebGL-сборке отрисовывалась частично (одна кнопка, ни одной надписи).

  Все подписи тестовой панели переведены и перестраиваются по событию смены языка,
