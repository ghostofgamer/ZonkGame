## 8. Онлайн (после выпуска)

Решение 28.10: **не к выпуску.** Живой онлайн — это сервер, обрывы связи, переподключение, защита от подмены
и подбор соперника, а на старте игроков мало — очередь будет пустой. «Сыграть с другом» уже закрывает игра вдвоём.
Шаг 1 (асинхронный Яндекса) — первым крупным обновлением, если аналитика покажет, что игроки возвращаются.

Ядро готово: партия детерминирована по сиду, случайность тратится только в `Roll`. По сети — три команды
(бросить / отложить / забрать), сервер пересылает и выдаёт случайность на каждый бросок (клиент не знает заранее).

- [ ] Шаг 1: асинхронный мультиплеер Яндекса (`ysdk.multiplayer.sessions`) — бесплатно, без сервера, соперник —
      записанная партия реального игрока. Только Яндекс.
- [ ] Шаг 2: игра с другом по коду комнаты. Варианты сервера: Cloudflare Workers + Durable Objects (бесплатно,
      но в РФ Cloudflare режут провайдеры с 06.2025 — проверить), российский VPS (~150–300 ₽/мес, надёжно),
      Yandex Cloud free tier (нужна карта). Решение — за автором.
- [ ] Случайный подбор соперника — не раньше, чем будет много игроков онлайн (иначе пусто).
