# Шрифты

`Roboto-Regular.ttf` — Google Roboto, лицензия Apache License 2.0, разрешено коммерческое использование.
Источник: https://github.com/googlefonts/roboto-2

Зачем свой шрифт: встроенный шрифт Unity в WebGL-сборке не рисует кириллицу,
потому что в браузере нет системных шрифтов, к которым он обращается.
Латиница и цифры при этом отображаются, из-за чего проблема выглядит как «пропали половина надписей».

Лежит в `Resources`, чтобы загружаться из кода: `Resources.Load<Font>("Fonts/Roboto-Regular")`.
Настройки импорта оставить по умолчанию: Character = Dynamic, глифы растеризуются в рантайме.
